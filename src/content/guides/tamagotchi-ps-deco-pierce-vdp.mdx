<section id="terminology">
## Understanding the P’s Pierce system

### Physical Tama Deco Pierce

A physical Deco Pierce is an accessory that connects to the Tamagotchi P’s and makes additional themed content available. Content varies between Pierces; do not assume every one supplies the same characters, items, locations, or activities.

### Deco Pierce patch / “12-hour patch”

When a Pierce is disconnected, the unmodified P’s eventually unlinks its Pierce content. The community therefore commonly calls Mr. Blinky’s modification the **12-hour patch**: it changes that retention behavior so linked Pierce or VDP content can remain available without a physical Pierce continuously attached. It is a prerequisite for the historical VDP workflow. “12-hour patch” is a community description, not an official Bandai product name.

### VDP

**VDP** means **Virtual Deco Pierce**. Historical project documentation describes VDPs as downloadable destinations that can be transferred and linked to the P’s to behave similarly to Pierce content. Some packages contain original characters and themed content. Their contents, number of files, evolution conditions, and credits can differ.

### VDP+

**VDP+** identifies virtualized Deco Pierce content within this ecosystem, including virtual representations of physical Pierce content where the project made them available. It is distinct from the custom-character VDP project. This guide does not claim that every physical Deco Pierce has a VDP+ counterpart.
</section>

<section id="english-patch">
## What the English patch does—and does not do

<Callout variant="warning" label="Separate patches">
The Tamagotchi P’s English translation patch and the Deco Pierce patch are separate modifications. Installing the English patch does **not** install the Deco Pierce/12-hour patch.
</Callout>

Historical VDP material recommends an English-patched P’s because VDP content was prepared with English-language data. That does not mean the English patch translates every physical Deco Pierce. Community reports say physical Pierce content can remain Japanese; TamaMedics has not yet independently reproduced that behavior.
</section>

- A Tamagotchi P’s.

- Mr. Blinky’s original Deco Pierce patch from the creator’s source.

### Option A — compatible infrared phone

Historically, community members have used infrared-equipped phones capable of sending the relevant download files. Compatibility depends on the handset and its transfer software. **Community method—TamaMedics verification pending.**

## Before you begin

<Callout variant="safety" label="Before you begin">
- Install reliable batteries; avoid starting with a low-power warning.
- Read the original README and package-specific instructions completely.
- Confirm every file is intended for the Tamagotchi P’s.
- Keep each original archive, README, and credit file together.
- Do not rename, omit, or reorder package parts unless its instructions say to.
- Do not mix unknown patches into this procedure.
- Once a patch execution begins, do not intentionally interrupt it.
</Callout>

This is a device modification, but the available evidence does not justify sensational claims about failure. The proportionate precautions are stable power, correct P’s files, an established transfer method, and strict adherence to creator documentation.
</section>

<section id="patch-installation">
## Install the Deco Pierce patch

### Step 1 — Obtain the original files

Open [Mr. Blinky’s Virtual Deco Pierce resources](http://mrblinky.net/tama/vdp/) and use the creator-provided Deco Pierce patch link and instructions. Do not substitute a similarly named file from an uncredited mirror. Retain the download archive and documentation as received.

<ImagePlaceholder description="Original source files and README on the computer; exclude personal paths." />

### Step 2 — Prepare the infrared transfer method

Set up a phone or computer/IrDA workflow already known to transfer P’s download files. Keep the transmitter and the P’s infrared window aligned at the distance recommended for that hardware. Close applications that could seize the adapter or interrupt the send.

### Step 3 — Transfer the patch

1. On the P’s, enter the appropriate download/receive state. **[Verify exact menu and button sequence during TamaMedics testing.]**
2. Start sending the patch file with the compatible infrared device.
3. Keep both devices steady until each reports success or failure.
4. If it fails, return both devices to their starting state before retrying; do not assume a partial transfer succeeded.

<ImagePlaceholder description="P’s download/receive menu before the patch transfer." />
<ImagePlaceholder description="Successful infrared patch transfer confirmation." />

### Step 4 — Run the transferred patch

Locate the transferred patch/destination on the P’s and run it exactly as the original documentation directs. **[Verify exact menu path, displayed title, prompts, and completion screen during TamaMedics testing.]** Do not remove batteries or press reset while it is executing.

<ImagePlaceholder description="Deco Pierce patch entry in downloaded destinations." />
<ImagePlaceholder description="Patch execution and completion screens." />

### Step 5 — Verify the patch

Confirm normal operation first. The meaningful functional check is whether linked Pierce/VDP content remains available after the unmodified device would normally unlink disconnected content. TamaMedics’ long-term retention test is pending, so the public status remains **verification pending**.
</section>

<section id="vdp-installation">
## Install and link a Virtual Deco Pierce

### Step 6 — Download a VDP

Choose a package from the original VDP page. Extract it without discarding its README, banner, or credits. Read its instructions before transferring anything. VDPs are not necessarily interchangeable in structure.

### Step 7 — Transfer every required file

1. Identify every required part from that package’s README.
2. Preserve the stated order. Do not assume all VDPs have the same number of parts.
3. Put the P’s into its appropriate receive state. **[Verify exact menu path during TamaMedics testing.]**
4. Send each required file, one at a time, confirming success before continuing.
5. If any part fails, consult the package instructions before restarting or resending the sequence.

<ImagePlaceholder description="VDP package parts and README before transfer." />
<ImagePlaceholder description="VDP infrared transfer in progress." />

### Step 8 — Link or activate the VDP

Open the transferred VDP destination and activate/link it according to its included directions. **[Verify the exact destination menu, activation prompts, and expected confirmation during TamaMedics testing.]** The Deco Pierce patch should already be installed before this step.

<ImagePlaceholder description="VDP destination before activation and the successful linked state." />

### Step 9 — Verify its content

Check the package documentation for the content it promises, then confirm only those elements. A character VDP may require a package-specific item or action during a particular growth stage, possibly multiple times. Gender, stage, item, and evolution conditions vary; never reuse one character’s conditions as a universal chart.

<section id="switching">
## Switching between VDPs and physical Pierces

The P’s normally treats Pierce content as one active link at a time, but the exact consequences of linking another VDP, inserting a physical Pierce, or intentionally removing content have not yet been reproduced by TamaMedics.

<Callout variant="warning" label="Needs verification">
Before switching while raising a Pierce-exclusive character, consult both packages’ original instructions. Whether the new link overwrites, unlinks, or is blocked by the current state must be recorded during live testing. Do not promise that a character or progress state will survive a switch.
</Callout>
</section>

<section id="recovery">
## Recovery and removal considerations

If a transfer fails before execution, stop and verify the source file, batteries, and transfer method rather than repeatedly sending unknown data. If the P’s still operates normally, preserve its current state and document the displayed error.

TamaMedics has not yet verified a universal removal or restore procedure for the Deco Pierce patch or every VDP package. Do not describe a reset, battery removal, or replacement transfer as “safe recovery” without creator instructions for that exact case. For an unresponsive or abnormal device, avoid further experimental patches and seek package-specific advice from the original source/community while recording what was sent and what the device displayed.

<Callout variant="note" label="Preservation record">
Keep the original archive, README, source URL, date obtained, transfer hardware/software, file order, device state, results, and photos of any error. That record is often more useful than a filename alone when a historical link disappears.
</Callout>
</section>

<section id="faq">
## Frequently asked questions

### Do I need the English patch?

The English translation is separate. Historical VDP documentation recommends it for English-prepared VDP content, but it does not replace the Deco Pierce patch.

### Do I need the Deco Pierce patch?

Yes for the documented historical VDP workflow: the patch prevents the disconnected-content unlink behavior that would otherwise undermine a virtual Pierce.

### Are VDP and VDP+ the same thing?

No. VDP refers to the virtual-content system and its custom packages; VDP+ labels virtualized physical-Pierce content offered within the project where available.

### Does every package use the same files or evolution conditions?

No. Treat each included README as authoritative for that package.

### Can I install another VDP or use a physical Pierce later?

**Needs verification.** One linked content set and character-state restrictions may affect switching. This guide will be updated after controlled tests.

### Does TamaMedics provide the downloads?

No. TamaMedics documents the procedure and links to creator sources. It does not redistribute third-party patch files, VDP archives, Bandai data, or artwork in this guide.
