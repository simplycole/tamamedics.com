## Live procedure observations

- Record the exact P’s menu labels, icon positions, button sequence, prompts, and success screen for receiving and running the patch.
- Record transfer hardware, operating system/software, file names, package README directions, order, distance/alignment, and retry behavior.
- Test patch retention beyond the unmodified unlink period and record elapsed time.
- Record the exact VDP destination/linking path and how success is shown.
- Test switching VDP to VDP, VDP to physical Pierce, and intentional unlink/removal without risking an active exclusive character.
- Determine whether a documented restore/removal procedure exists; do not infer one from reset behavior.
- Replace each public verification marker only after reproducing it.

## Credit/source review
